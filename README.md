# ふたりのホーム

しゅうくんとあいちゃん専用のホーム。お金・やること・書類・写真をまとめて見られます。

- サイト：https://shutasengoku.github.io/futari-home/
- データ：しゅうくんの Googleドライブ「ふたりのホーム」フォルダ（このリポジトリには入りません）

## しくみ

| 部品 | 場所 | 役割 |
|---|---|---|
| 画面 | このリポジトリ（GitHub Pages） | `index.html` `app.css` `app.js` |
| 設定 | `config.js` | OAuth クライアントID と窓口のURL（公開してよい値だけ） |
| 窓口 | Apps Script（`apps-script/Code.gs` を貼ったもの） | Googleログインを確認し、ドライブを読み書き |
| データ | Googleドライブ | 台帳・やること・写真 |

## 安全のための決まり

- 使えるのは、台帳「設定」タブのL列にメールアドレスが入っている人だけ。
- 一度ログインすると30日間有効。「ログアウト」でその端末のログインを消せます。
- パスワードや個人情報など、データそのものはこのリポジトリに置かない。

## 窓口を更新するとき

1. `apps-script/Code.gs` の内容を Apps Script に貼り付けて保存
2. 「デプロイ」→「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」→「デプロイ」（URLは変わらない）
